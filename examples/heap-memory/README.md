# 図とアニメーションの教材サンプル

heap教材で使った説明方法を5ページにまとめたサンプル。テーマは `midnight-dark`。詳細なmalloc実装を説明する教材そのものではなく、図・強調・説明の区切りを再利用するための例。

`index.html` をブラウザで開き、右キーで進める。共有CSS・JSを含むリポジトリ一式が必要だが、ビルドや外部APIは不要。

| Step（URLでは0始まり） | 内容 | 右キーで進む単位 |
| --- | --- | --- |
| 1 | stack | push / popを1操作ずつ。Cを取り出してD、Eを積む |
| 2 | 状態変化 | 解放による見た目の変化 → 管理側からの参照 |
| 3 | メモリへの参照 | mallocの返り値からユーザー領域へ矢印 → 到着後に枠 |
| 4 | 循環リンク | fd一周 → bk一周（点線） |
| 5 | 分類の対応 | 同じサイズの見出し・領域を同じ単色で結ぶ |

`?step=3&cue=1` でfd一周が完了したところを直接開ける。台本・画面仕様は [storyboard.md](storyboard.md)、共通の制作方針は [docs/design.md](../../docs/design.md)。
