# ブラウザでの確認

教材の閲覧・編集に以下のライブラリは不要。共通の操作や表示を変更するときの開発用確認。

PythonのPlaywrightとChromiumが利用できる環境で、ルートから実行する。

```bash
python3 tests/browser.py
```

別のChromiumを使う場合は、環境変数 `CHROMIUM_PATH` に実行ファイルのパスを指定する。結果と画面画像はGit対象外の `tmp/browser-checks/` に出力する。

確認対象:

- heapサンプルの手動再生・停止・巻き戻し・URL復元・fd/bk一周・状態変化と参照の順序。
- テンプレートとサンプルの1980×1020、1440×900、844×390、390×844での表示。
- テンプレートを `lessons/<lesson-id>/` へ複製した場合の共有ファイルの読み込み。
- `classic-light` のテーマ切り替えと、従来の鍵交換サンプルの操作。
- スクリプトエラー、必須ファイルの読み込み失敗、フォーカス中の入力欄やボタンのキー操作。

サンプルを差し替えた場合は、タイトルや動きの数などの期待値も台本と一緒に更新する。数式ライブラリは従来サンプルのみ外部CDNから読み込むため、このテストではそのネットワークを止めて確認し、MathJax自体のレンダリングは対象外とする。

## 統合時の結果

2026-09-30、Chromiumで121項目を確認して通過。PCの紺／明るいテーマ、スマホ幅のstack、参照先の強調とリンク図も画像で確認した。
