# テンプレートの由来

## 既存の構成

このリポジトリの初期コミットは `43f1b76`。`templates/html-lesson/` を複製し、`storyboard.md` を台本・画面仕様の正本として、HTML/CSS/JavaScriptを直接編集する構成だった。共有Slide Kitにはisogeny教材由来の部品が含まれていた。

## heap教材からの抽出

heap教材の制作中に、口頭で説明しやすい図、配色の意味、動画への切り出し、手動アニメーションの方針を段階的に整理した。2026-09-29に、それらをローカルの `slide-kit-v2` として保存した。

そのローカル保存版には、旧Slide Kit、設計メモ、ソースのハッシュ、検証結果も含めている。ただし、それ以前の教材の全編集をGitの差分として復元できるという意味ではない。チャット、作業コピー、途中のスクリーンショットとして残る履歴もある。

## 2026-09-30 — このリポジトリへの統合

ローカル保存版の配色と動きを、このリポジトリの既存構成に合わせて統合した。

- `docs/design.md` に色コード、強調の判断基準、説明順序、収録・スマホの方針を保存。
- 共通の時計・矢印・表示制御を `shared/slide-kit/` に配置。
- 既存の `templates/html-lesson/` を更新。`index.html`、`lesson.css`、`lesson.js`、`storyboard.md` の編集方法を維持。
- `examples/heap-memory/` に5枚の説明例を追加し、台本と確認できるようにした。
- 0始まりの `?step=` を継続し、ページ内の完了した動きの数に `&cue=` を追加。
- 生成HTMLを作るビルド工程は持ち込まず、共有ファイルを通常のscriptとして読み込む方式に変更。
- 元の鍵交換サンプルと、明るいテーマを引き続き利用可能にした。

以後の更新はこのリポジトリのコミットで追える。個別の教材の判断はその `storyboard.md`、全体の方針は `docs/design.md` に記録する。
